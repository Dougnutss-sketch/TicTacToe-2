# 🎮 Tic Tac Toe Game

Project ini adalah permainan **Tic Tac Toe (X dan O)** sederhana yang dibuat menggunakan:

- HTML
- CSS
- JavaScript

## 🚀 Cara Menjalankan
1. Clone repository ini:
   git clone https://github.com/Dougnutss-sketch/TicTacToe-2
   
3. Buka folder project di VS Code

4. Jalankan file Tictactoe.html di browser.


🧩 Fitur
-Dua pemain (X dan O)
-Deteksi pemenang otomatis
-Pesan "Menang" dan "Seri"
-Tombol reset game
